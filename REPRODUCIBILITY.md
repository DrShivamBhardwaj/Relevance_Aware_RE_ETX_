# Reproducibility Guide

## Overview

This document describes the procedure used to reproduce the simulation experiments reported in the manuscript:

**"Relevance-Aware RE-ETX Semantic Routing for Wireless Sensor Networks"**

The repository provides the complete simulation framework, experiment scripts, and generated results required to reproduce the reported evaluation.

The implementation evaluates the impact of reliability-aware routing, semantic routing decisions, and semantic payload optimization on wireless sensor network lifetime and communication efficiency.

---

## Software Environment

The experiments were executed using Python 3.x.

Required Python packages:

- NumPy
- Pandas
- SciPy
- Matplotlib
- NetworkX
