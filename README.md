# RE-ETX payload allocation validation

This branch develops code fixes and Cooja validation for the archived ten-seed C1–C7 study. It contains code, simulation configurations and numerical evidence. Manuscripts are not maintained on this branch.

Historical results remain under results/master_validation. New experiments have their own provenance and do not overwrite or relabel those historical outputs.

See validation/cooja/README.md and the Cooja validation workflow for execution status. A configured workflow or successful build alone is not an executed research result.
